# ZIZIYI Office

本地优先的浏览器 Office 套件，直接在浏览器中查看和编辑 Word（.docx）、Excel（.xlsx）、PowerPoint（.pptx）文档。安装后自动完成 VOS 免登录，并直接访问安装时选择的映射文档目录。

## 功能

- 打开和编辑 `.docx`、`.xlsx`、`.pptx` 文档
- VOS 免登录：自动完成 VOS OIDC Fastpath 认证，无需手动登录或反复跳转
- 映射目录直读写：直接列出、打开和保存宿主机映射文档目录根层级中的文件
- 快速创建新文档（Word / Excel / PPT）
- 本地文件同样可以直接打开编辑（本地优先）

## 使用

安装后在 VOS 平台侧边栏找到 **ZIZIYI Office**，打开即可：

1. 首页"云端文档"列出映射文档目录中的文件，点击直接打开
2. 从首页新建文档或打开本地文件进行编辑
3. 在编辑器中保存（Ctrl+S）时，文档直接写回映射文档目录；保存失败会保持错误状态，不会改成浏览器下载

## 说明

- 安装时可配置"文档存储路径"（宿主机目录），应用直接访问该目录根层级中的受支持文档。
- 未接入 VOS 的独立部署保持原有行为：文档保存在浏览器本地（IndexedDB / 本地文件句柄），不依赖服务端。
