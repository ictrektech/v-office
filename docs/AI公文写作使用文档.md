# AI 公文写作 · 使用文档

AI 公文写作基于 agentic-search 智能体服务，只需上传一份参考材料、选择文种、填写写作要求，即可自动完成起草、审查、定稿的全流程，并导出符合公文版式的 Word / PDF / Excel 文档。

---

## 一、界面总览

进入「AI 公文写作」后，页面分为两个区域：

| 区域 | 说明 |
| --- | --- |
| **左栏 · 参考材料** | 上传本地文件或选择云端文件，下方为「最近使用」历史记录 |
| **右侧 · 写作配置与生成** | 依次完成：选择文种 → 选择 Agent → 填写写作要求 →（可选）高级设置 → 开始生成 |

---

## 二、快速上手（四步生成一篇公文）

### 第 1 步：选择参考材料

在左栏上传一份材料，作为本次写作的素材来源。

- **本地**：点击上传区域选择文件，或直接把文件拖拽到上传框；支持 Word / PDF / 表格 / 文本
- **云文档**：直接选用 v-office 云端文件，无需下载到本地再上传
- **最近使用**：上传过的材料会出现在此列表，点击即可快速再次使用
  - 成稿过的文档记录保存在服务端，换浏览器、换设备登录后依然可见
  - 刷新页面后会自动恢复上次的成稿与生成过程，无需重新生成

> 上传后系统会自动解析材料内容，并显示解析出的字数。

### 第 2 步：选择文种

在文种列表中点选一种公文类型，共 22 种：

红头文件、通知、请示、批复、工作报告、调研报告、领导讲话稿、会议纪要、可行性研究报告、项目立项建议书、工作/实施方案、工作总结、述职报告、汇报材料、管理制度/办法、工作简报、政策解读材料、新闻宣传稿、大事记、倡议书/公开信、数据统计报表、会议方案、经验交流材料

不同文种会自动套用对应版式：

- **红头版式文种**（红头文件、通知、请示、批复、工作报告、调研报告、会议纪要）：会出现「发文字号」输入框（如 `X政发〔2026〕5号`），导出时按 GB/T 9704-2012 标准加红头
- **述职报告**：报告版式，文末署名落款
- **领导讲话稿**：演讲版式，加宽行距
- **数据统计报表**：导出 Word 正文 + Excel 附表

### 第 3 步：选择 Agent

可选择 **Claude Code** 或 **OpenCode** 两种智能体驱动本次写作。

> 注意：所选 Agent 需要在 agentic-search 服务中配置对应的 agent provider，否则生成会失败。

### 第 4 步：填写写作要求（必填）

在「写作要求」中描述本次写作的核心需求，这是必填项。例如：

```
解读××年度财政预算报告，面向公众发布，通俗易懂，重点包括预算数字与民生
```

写清「主题 + 面向谁 + 侧重什么」，生成效果最好。

### 第 5 步：开始生成

点击底部「开始生成」按钮，进入自动写作流程。

---

## 三、可选设置

以下设置均非必填，按需使用。

### 基础信息（补充公文的结构性要素，可留空）

| 字段 | 说明 |
| --- | --- |
| 引用知识库 | 点选标签引用平台知识库（如「法律条文」「合同智能档案」），为写作提供权威依据 |
| 发文机关 | 公文的落款/发文单位名称 |
| 发文 / 解读对象 | 公文面向的对象或解读的目标文件 |
| 行文口径 / 解释形式 | 行文的口径要求或解释形式 |

> 没有特殊的格式要求可以不用填写，系统会根据文种自动处理。

### 其他要求（选填）

有其他明确的写作要求时在此填写，例如：

```
结合本单位实际情况，重点写明确措施部分；文中数据以上年度报表为准。
```

### 篇幅设置（选填）

设定生成 Word 文档的目标字数。

- 留空或填 `0`：由模型自由发挥
- 填写具体数字（如 `3000`）：生成内容会尽量贴合该篇幅

---

## 四、生成过程

点击「开始生成」后，系统按三阶段流水线自动写作，全程可视化：

1. **✍️ 写手起草**：根据材料与要求完成初稿
2. **🔍 审查改稿**：审查初稿并自动修正问题
3. **🏛️ 审批定稿**：最终把关并定稿

每个阶段的卡片会展示智能体的**思考过程、输出内容与使用的工具**，可实时掌握写作进展。顶部会显示当前所处阶段，生成期间可随时点击「停止」终止本次写作。

---

## 五、成稿后的操作

生成完成后，页面下方会出现成稿预览与「文档导出」区（导出后自动同步至稿内库）。

### 导出文档

| 按钮 | 说明 |
| --- | --- |
| **下载 Word** | 导出 .docx，自动套用所选文种的公文版式 |
| **下载 Excel** | 数据统计报表类文种附带的附表 |
| **下载 PDF** | 将 Word 转换为 PDF 下载 |
| **下载 PPT** | 部分文种支持导出 PPT |
| **上传到云端** | 把当前成稿（最新版）导出并上传到 v-office 云端文件（登录模式下可用） |

### 局部微调

在「局部微调」输入框中用自然语言描述修改要求，例如：

```
把落款改为「市政务服务和数据局」；第二段补充数据来源
```

发送后系统按指令修订，完成后自动更新成稿并重新导出文件，无需从头生成。

### 撤销修改

对微调结果不满意时，点击「↩ 撤销本次修改」回退到上一版成稿并重新导出文件（无 LLM 调用，立即完成）。可连续撤销多版。

### 重新生成

点击「← 调整设置重新生成」回到配置页，修改文种、要求或材料后重新生成。

## 六、保存文档

成稿（以及每次微调后的最新版）都可以保存下来，共以下几种方式：

### 1. 下载 Word（推荐）

点击「下载 Word」，导出 .docx 文件到本地：

- 自动套用所选文种的公文版式（红头文种按 GB/T 9704-2012 加红头、发文字号）
- 下载后**自动同步至稿内库**，在平台内可随时找到这份文档
- 微调 / 撤销后再次下载，得到的始终是当前最新版

### 2. 下载 PDF

点击「下载 PDF」，系统将当前成稿的 Word 转换为 PDF 后下载，适合正式分发、存档场景。

### 3. 下载 Excel 附表

数据统计报表类文种除 Word 正文外，还会生成 Excel 附表（数据表格），点击「下载 Excel」单独保存。

### 4. 上传到云端

点击「上传到云端」，把当前成稿（最新版）导出并上传到 **v-office 云端文件**：

- 仅登录（VOS）模式下显示该按钮
- 上传成功后按钮显示「已上传云端」，可前往 v-office 的云文件 / 文档管理中查看
- 上传的始终是当前最新版：微调后再次上传即覆盖为新版本

### 保存位置一览

| 保存方式 | 文件去向 | 适用场景 |
| --- | --- | --- |
| 下载 Word / PDF / Excel | 本地电脑 + 自动同步稿内库 | 本地编辑、打印、归档 |
| 上传到云端 | v-office 云端文件 | 云端留存、跨设备访问、后续引用为写作材料 |

> 建议：成稿后先「上传到云端」留一份云端存档，再按需下载 Word 到本地；微调定稿后记得重新上传，保证云端是最新版。

## 七、数据保存与恢复说明

| 数据 | 保存位置 | 说明 |
| --- | --- | --- |
| 上传的材料 + 最近使用记录 | 浏览器本地（IndexedDB） | 按登录用户隔离；清除浏览器数据或更换浏览器后，本地材料记录不可见 |
| 成稿文档记录（最近使用中的成稿项） | 服务端（入库存储） | 跨浏览器、跨设备一致，登录同一账号即可看到 |
| 生成过程（各阶段思考与输出）与成稿版本栈 | 服务端（持久化存储） | 刷新页面后自动恢复成稿与过程卡片，微调 / 撤销可继续使用 |

**常见问题**：

- **刷新后刚进入页面列表短暂为空？** 属正常加载过程，系统会显示「正在加载最近文件…」并自动重试；若服务暂时不可用，恢复后列表会自动补全。
- **点击最近使用的历史项没有材料内容？** 该记录来自服务端（原浏览器材料记录已不在），重新上传同名材料即可继续微调或再次生成。

---

## 八、使用建议

1. **材料越完整，成稿质量越高**：优先上传内容翔实的参考材料，云端文件可直接选用
2. **写作要求写具体**：明确主题、受众、侧重点，避免「写一份报告」这类过于宽泛的描述
3. **善用微调而非重新生成**：小改动用局部微调，速度快且保留其余内容
4. **数据类文种记得核对数字**：涉及数据统计报表时，建议导出 Excel 附表核对数据来源
