# ZIZIYI Office

Local-first browser office suite for viewing and editing Word (.docx), Excel (.xlsx) and PowerPoint (.pptx) documents entirely in the browser.

## Features

- Open and edit `.docx`, `.xlsx` and `.pptx` documents
- Local-first: documents are processed in the browser and stored in IndexedDB, never uploaded
- Quickly create new Word / Excel / PowerPoint documents
- Pick files from Google Drive, Dropbox and OneDrive via Uppy

## Usage

After installation, open **ZIZIYI Office** from the VOS sidebar:

1. Create a new document from the home page, or open a local Office file
2. View and edit in the editor; changes are stored locally in the browser

## Notes

- The app is a pure static frontend with no server-side component; local files are independent per browser and device.
- Clearing browser site data removes locally saved documents; export important files regularly.
