# V-Office

本地优先的浏览器 Office 套件，直接在浏览器中查看和编辑 Word（.docx）、Excel（.xlsx）、PowerPoint（.pptx）文档。安装后自动完成 VOS 免登录，并使用 VOS 自动分配的应用私有存储。

## 功能

- 打开和编辑 `.docx`、`.xlsx`、`.pptx` 文档
- VOS 免登录：自动完成 VOS OIDC Fastpath 认证，无需手动登录或反复跳转
- 用户目录直读写：每个用户只列出、打开和保存应用私有存储中 `<用户名>/` 下的文件，并可逐文件打开或下载
- Agent API：内置 API 接入指南，可通过 VOS OIDC Token 列出、下载、上传覆盖和删除当前用户文档
- 快速创建新文档（Word / Excel / PPT）
- 本地文件同样可以直接打开编辑（本地优先）

## 使用

安装后在 VOS 平台侧边栏找到 **V-Office**，打开即可：

1. 首页"云端文档"列出当前用户专属目录中的文件，可直接打开或下载
2. 从首页新建文档或打开本地文件进行编辑
3. 新文档第一次保存（Ctrl+S）时输入文件名，之后直接写回同一文件；右上角可关闭当前文档
4. 从左侧"API 接入指南"查看接口地址、认证要求和可复制的 Agent 调用示例

## 说明

- 文档路径无需安装时配置；VOS 自动分配应用私有存储，应用按 VOS 用户名建立隔离子目录。该目录不出现在公共文件中，用户之间不能互相访问文档。
- 从旧版公共目录升级时，原目录和文件保持不动，不会自动迁移或删除。
- 未接入 VOS 的独立部署保持原有行为：文档保存在浏览器本地（IndexedDB / 本地文件句柄），不依赖服务端。
