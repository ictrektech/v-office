# ZIZIYI Office

本地优先的浏览器 Office 套件，直接在浏览器中查看和编辑 Word（.docx）、Excel（.xlsx）、PowerPoint（.pptx）文档，文件全程留在本机。

## 功能

- 打开和编辑 `.docx`、`.xlsx`、`.pptx` 文档
- 本地优先：文档在浏览器内处理并保存到 IndexedDB，不上传服务器
- 快速创建新文档（Word / Excel / PPT）
- 通过 Uppy 从 Google Drive、Dropbox、OneDrive 选择文件

## 使用

安装后在 VOS 平台侧边栏找到 **ZIZIYI Office**，打开即可：

1. 从首页新建文档，或打开本地 Office 文件
2. 在编辑器中查看和编辑，改动自动保存在浏览器本地

## 说明

- 应用为纯静态前端，无服务端组件；不同浏览器、不同设备的本地文件互相独立。
- 清除浏览器站点数据会删除已保存的本地文档，请定期导出备份。
